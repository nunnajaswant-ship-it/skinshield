## Slides

1. **Title** — SkinShield: A Multimodal Edge-AI Framework for Real-Time Skin Disease Detection, Triage and Referral. Team: N. Jaswanth Sriram (Team Leader), Harini Shree R (Research Scholar), Dr. K. Deepa (Professor), Amrita Vishwa Vidyapeetham.
2. **Ideology of the Proposed Research Framework** — the full flowchart: image + symptom text + IoT sensor data → preprocessing / sensor conditioning → feature extraction → multimodal fusion → Stage 1 contagion gate → Stage 2 disease identification → explainable output → edge deployment → performance evaluation.
3. **Key Research Activities and Proposed Work** — five work packages: multimodal data integration, multimodal feature learning, two-stage safety-gated classification, edge deployment on Raspberry Pi / Jetson, and clinical validation with responsible AI.
4. **Support Needed** — from research to real-world rural healthcare: AI development, clinical partnerships, edge hardware, computing and storage, rural pilot access, funding and mentorship.
